# Ugray Consulting Limited - Professional Website

A modern, responsive website for Ugray Consulting Limited, built with mobile-first design principles and inspired by McKinsey & Company's professional aesthetic.

## 🎨 Design Features

- **McKinsey-Inspired Layout**: Clean, professional design with strategic use of white space
- **Color Scheme**: Black title background with navy and grey accents as requested
- **Mobile-First Responsive**: Optimized for all devices (320px to 1200px+)
- **Professional Typography**: Inter font family for modern, readable text
- **Smooth Animations**: Subtle fade-in effects and smooth scrolling
- **Accessibility**: WCAG compliant with proper focus states and keyboard navigation

## 📱 Responsive Breakpoints

- **Mobile**: 320px - 767px
- **Tablet**: 768px - 1023px  
- **Desktop**: 1024px - 1199px
- **Large Desktop**: 1200px+

## 🛠 Deployment Options

### Option 1: Static Hosting (Recommended for Budget)
**Free/Low-Cost Options:**
- **Netlify**: Free tier with custom domain support
- **Vercel**: Free hosting with excellent performance
- **GitHub Pages**: Free with GitHub repository
- **Firebase Hosting**: Google's free tier

**Steps:**
1. Create account on chosen platform
2. Upload website folder or connect GitHub repository
3. Configure custom domain (ugrayconsulting.com)
4. Enable HTTPS (usually automatic)

### Option 2: Traditional Web Hosting
**Budget-Friendly Options:**
- **Namecheap**: $2-5/month with domain included
- **Bluehost**: $3-7/month with WordPress option
- **SiteGround**: $4-8/month with excellent support

### Option 3: Content Delivery Network (CDN)
- **Cloudflare Pages**: Free with global CDN
- **AWS S3 + CloudFront**: Pay-as-you-go pricing

## 🔧 Customization Guide

### Adding Your Content
1. **Logo**: Replace "Ugray Consulting" text with your logo image
2. **Images**: Add professional photos to `/images/` folder
3. **Content**: Update text content in `index.html`
4. **Contact Info**: Update phone, email, and address details
5. **Colors**: Modify CSS variables in `:root` section if needed

### SEO Optimization
1. **Google Analytics**: Add tracking code before `</head>`
2. **Google Search Console**: Verify domain ownership
3. **Local SEO**: Add Google My Business listing
4. **Meta Tags**: Update title and description for each page

### Performance Optimization
1. **Images**: Compress images before uploading
2. **Fonts**: Consider using system fonts for faster loading
3. **Caching**: Enable browser caching on your hosting platform
4. **Minification**: Minify CSS/JS for production

## 📧 Contact Form Setup

The contact form includes client-side validation. For full functionality, you'll need to:

1. **Option 1 - Form Service (Easiest)**
   - Use Netlify Forms (free with Netlify hosting)
   - Use Formspree.io (free tier available)
   - Use EmailJS for client-side email sending

2. **Option 2 - Server-Side Processing**
   - Add PHP script for form processing
   - Use Node.js with Express for form handling
   - Integrate with email service (SendGrid, Mailgun)
